WinProgramManager - Changelog

Version 2026.02.21.07 - February 21, 2026

🔴 BREAKING CHANGES - Multi-User Database Support
  • Database Location Changed: Databases now stored in C:\ProgramData\WinProgramManager\ instead of the executable directory
  • Automatic Migration: On first run, databases are automatically moved from the installation directory to ProgramData
  • Shared Access: All Windows users on the same machine now share the same database instance
  • Permissions: Requires write access to ProgramData (typically available to all users)
✨ New Features
  • Multi-User Support: Multiple Windows users can now use WinProgramManager simultaneously with shared database
  • Database Migration Utility: New db_path_utils.h provides centralized path management
  • Automatic First-Run Migration: Seamlessly moves databases to ProgramData without user intervention
  • Cross-Drive Support: Migration handles cross-drive scenarios with copy+delete fallback
🔧 Technical Improvements
  • Unified Path Management: All components (Manager, UpdaterGUI, UpdaterConsole) use consistent path logic
  • FOLDERID_ProgramData: Uses Windows Known Folder API for reliable ProgramData location
  • Error Handling: Improved error messages with specific path information and permission guidance
  • Search Database: Temporary search database also moved to ProgramData for consistency
📦 Distribution Changes
  • Database (WinProgramManager.db) continues to ship in the installation directory
  • On first launch, database is automatically moved to C:\ProgramData\WinProgramManager\
  • Subsequent installations/uninstallations preserve the ProgramData database
🔄 Migration Behavior
  • First Run: Database moves from installation directory → ProgramData
  • Already Migrated: No action taken, uses existing ProgramData database
  • No Database Found: Error displayed (fresh install should include database)
  • Search Database: Migrated if exists, otherwise created fresh in ProgramData
💻 Affected Components
  • WinProgramManager.exe: Main application - migrates on launch
  • WinProgramUpdaterGUI.exe: GUI updater - migrates on launch
  • WinProgramUpdater.exe: Legacy silent updater - migrates on launch
  • WinProgramUpdaterConsole.exe: Legacy console updater - migrates on launch
📝 Files Modified
  • db_path_utils.h (NEW) - Centralized database path management and migration logic
  • main.cpp - Updated to use ProgramData path with migration
  • updater_gui.cpp - Updated to use ProgramData path with migration
  • updater_main.cpp - Updated to use ProgramData path with migration
  • WinProgramUpdater.cpp - Updated search database to use ProgramData
